# Netflix Data Analysis Using Python

## Project Overview
This project focuses on analyzing the Netflix dataset using Python to understand content distribution, country-wise contributions, release-year trends, content ratings, and genre patterns.

The project was completed as part of the **Data Analysis Using Python Internship at AuspiFy Technologies**.

## Tasks Completed

1. **Netflix Data Cleaning & Preparation**  
   Handled missing values, checked duplicate records, standardized data, and exported the cleaned dataset.

2. **Content Type Analysis**  
   Analyzed Movies and TV Shows distribution and created visualizations to compare content types.

3. **Country-Wise Content Analysis**  
   Identified top content-producing countries and compared Movies and TV Shows across countries.

4. **Release Year Trend Analysis**  
   Analyzed content distribution by release year and identified growth and decline patterns.

5. **Content Rating & Genre Analysis**  
   Examined content ratings, popular genres, and differences between Movies and TV Shows.

6. **Netflix Business Insights Report**  
   Performed exploratory data analysis, created a business dashboard, and summarized key findings and recommendations.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook
- Visual Studio Code

## Dataset Information

- Dataset: Netflix Movies and TV Shows
- Total Records: 8,790
- Total Columns: 10
- Source file: `Task_1_Data_Cleaning/dataset/Dataset.csv`
- Cleaned dataset: `Task_1_Data_Cleaning/output/Netflix_Cleaned.csv`

## Project Structure

The project is organized into six task-wise folders. Each task contains its corresponding Jupyter Notebook. The `Screenshots` folder contains output screenshots organized by task.

## How to Run

1. Install Python.
2. Install the required libraries using `pip install -r requirements.txt`.
3. Open the project folder in Visual Studio Code.
4. Open the required Jupyter Notebook.
5. Select a Python kernel and run the notebook cells.

## Conclusion

This project demonstrates practical data analysis skills, including data cleaning, exploratory data analysis, data visualization, trend identification, and business insight generation using Python.

**Internship Organization:** AuspiFy Technologies
